# Support

## Getting Help

For usage questions, start by checking `README.md`, especially the sections on launching the container, route/proxy mode, and autostart logs.

## Reporting Bugs

When opening a bug report, include:

- Host OS and version
- Docker version
- Desktop session type, for example X11 or Wayland
- AppImage version and path
- Output from `docker ps --filter name=cc-switch-gui`
- Relevant lines from `~/.local/state/cc-switch-docker/autostart.log`

Do not include API keys, provider credentials, or private configuration files.

## Feature Requests

Feature requests are welcome when they improve container reliability, portability, documentation, or safe integration with host CLI tools.
